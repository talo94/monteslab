# Montes Lab

Espacio personal y público para publicar ideas, viajes, música y proyectos.

Construido con React, Vite, TypeScript, Tailwind y React Router; desplegado en Vercel.

## Desarrollo

```bash
npm ci
npm run hooks:install
npm run dev
```

Usa Node.js 22.12 o posterior. Para verificar cambios:

```bash
npm run test   # Integridad de las guías de viaje
npm run check  # Formato, lint, tipos y pruebas
npm run build  # Controles y compilación de producción
```

Consulta [CONTRIBUTING.md](CONTRIBUTING.md) para conocer el flujo de Git, los controles de calidad y las normas de publicación.

La documentación viva del producto y su arquitectura comienza en [docs/README.md](docs/README.md).
